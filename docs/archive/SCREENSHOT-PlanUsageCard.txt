DETALLES VISUALES:

1. HEADER (Gradiente Azul)
   - Fondo: Gradiente de #2563eb a #1d4ed8
   - Texto: Blanco (#ffffff)
   - Icono: Corona (👑) dorada
   - Tipografía: Título en 2xl bold, precio en text-blue-100

2. BOTÓN "ACTUALIZAR PLAN"
   - Color: bg-yellow-500 hover:bg-yellow-600
   - Icono: TrendingUp (⬆)
   - Texto: Blanco
   - Bordes redondeados: rounded-lg
   - Solo visible si shouldUpgrade = true

3. ALERTA DE UPGRADE
   - Fondo: #fef3c7 (yellow-50)
   - Borde izquierdo: 4px #eab308 (yellow-500)
   - Icono: AlertTriangle (⚠️) amarillo
   - Texto: #92400e (yellow-800)

4. BARRAS DE PROGRESO
   - Altura: 10px (h-2.5)
   - Fondo gris: #e5e7eb (gray-200)
   - Bordes redondeados completos
   - Animación: transition-all duration-300
   - Colores dinámicos según porcentaje:
     * < 50%: bg-green-500 (#22c55e)
     * 50-74%: bg-blue-500 (#3b82f6)
     * 75-89%: bg-yellow-500 (#eab308)
     * >= 90%: bg-red-600 (#dc2626)

5. FEATURES
   - Grid 2 columnas en desktop
   - Checkmark verde (✅): CheckCircle lucide, #16a34a
   - X gris (❌): XCircle lucide, #9ca3af
   - Texto disponible: text-gray-900
   - Texto no disponible: text-gray-500 + line-through
   - Tooltip en hover muestra descripción

6. TIPOGRAFÍA
   - Título plan: text-2xl font-bold
   - Precio: text-blue-100
   - Labels barras: font-medium text-gray-900
   - Valores: text-sm font-semibold
   - Porcentajes: text-xs font-medium (color según umbral)

RESPONSIVE BREAKPOINTS:

Mobile (< 768px):
- Card ocupa 100% ancho
- Features en 1 columna
- Padding reducido

Tablet (768px - 1023px):
- Card ocupa 100% ancho
- Features en 2 columnas

Desktop (>= 1024px):
- Card ocupa 1/3 del grid (lg:col-span-1)
- Features en 2 columnas
- Layout óptimo con sidebar
